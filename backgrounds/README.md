# CEDAR wallpapers

Three original widescreen wallpaper assets generated for the CEDAR theme. The PNGs are bundled at `themes/backgrounds/`, where Omarchy's theme background switcher can find them. `themes/preview.png` gives the graphical theme picker a matching forest preview.

- `01-cedar-woods.png` — layered Appalachian ridges, hemlocks, valley fog and bioluminescent fungi glowing on a fallen log.
- `02-field-station-grid.png` — near-black forest green, thin teal calibration grid, quiet central reticle and faint green light.
- `03-cedar-mycelium.png` — luminous fungal threads and subtle circuit branches around a calm dark center.

The procedural Quickshell background remains available as the fourth option when using the shell. To refresh Omarchy's wallpaper thumbnails after replacing images, run `omarchy theme bg cache` if the command is available, or switch to another CEDAR background and back.
