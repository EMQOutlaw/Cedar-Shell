# Credits, source licensing and Scripture

The inherited source snapshot has no original-source license declaration. This migration does not invent one or claim that the whole project is MIT licensed. A maintainer must choose/confirm original-source and asset licensing before public distribution.

`components/MenuModel.js` includes adapted Omarchy menu helpers under MIT. The full upstream notice is retained in `licenses/Omarchy-MIT.txt`; source: https://github.com/basecamp/omarchy/blob/master/LICENSE. Required copyright attribution is not private developer biography and must remain.

Qt, Quickshell, Hyprland, Linux services, fonts and optional tools are dependencies with their own licenses; their binaries and fonts are not bundled. Rajdhani is preferred for interface text, JetBrainsMono Nerd Font for data; readable system sans-serif/monospace fallbacks are used when unavailable. Inspect the selected font distributor's license before adding font files to a future release.

Weather comes from Open-Meteo and retains on-screen attribution. Existing woodland artwork is carried forward without a new licensing assertion. Screenshots used for tests contain synthetic fixtures, never exports of private desktop data.

## Scripture

The locally approved Psalm 92:12 and John 3:16–17 wording uses the **King James Version (KJV)**. The technical acronym and “Rooted in faith. Built with care.” are original project wording, not Bible quotations. Values drawn from the cedar imagery are this project's interpretation and application.

Do not assume identical redistribution rules for all Bible translations or all jurisdictions. In the United Kingdom, rights in the Authorized (King James) Version are administered under the Crown's printer arrangements; consult Cambridge's current permissions guidance for intended distribution. No claim of worldwide public-domain status or a new permission grant is made here.

Authoritative guidance: https://www.cambridge.org/cu/rights-and-permissions/permissions-faqs and https://www.cambridge.org/us/rights-and-permissions/permissions . Scripture attribution is separate from the software and upstream notices.
